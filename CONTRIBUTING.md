# Contributing

Use synthetic node inventories, PCM fixtures and mock write operations. Run `python3 -B -m unittest discover -s tests`, `luajit tests/bound_proxy.lua` and `python3 scripts/package.py`. No daemon or audio hardware is needed. Describe the tested environment and distinguish simulated results from device tests. Record the source and rights of every contribution, including artwork and AI assistance.

OpenAction submission is pending namespace review and disposable-host qualification. Keep the bundle and action IDs stable. Follow the [official catalogue instructions](https://github.com/OpenActionAPI/plugins), set flags.ai_assisted to true, supply a matching PNG icon and use the openaction repository topic. No publishing credentials are required for offline CI.
