# Provenance of the distributed components


**Transport.** The inherited handshake and frame code was removed. meter.py adapts the synchronous connect/send/recv API of websockets 16.0. The address is literal IPv4 loopback with proxies, compression and periodic pings disabled. Both installation modes run this bundled Python client inside OpenDeck. Python 3.10 or later is required. No pip invocation or network dependency resolution is needed. The published pure-Python wheel websockets-16.0-py3-none-any.whl was verified against its PyPI SHA-256 (1637db62fad1dc833276dded54215f2c7fa46912301a24bd94d45d46a011ceec). Only the synchronously imported Python modules and upstream license were retained. No native speedup, legacy or asyncio implementation is shipped. The upstream BSD-3-Clause text and attribution travel inside the ZIP. [Official source](https://github.com/python-websockets/websockets/tree/16.0) · [Client API](https://websockets.readthedocs.io/en/stable/reference/sync/client.html).

**Lua helper.** The implementation inputs for this revision were the approved project behavior, control.py's JSON request and existing bound_proxy.lua fixtures. Resolve exactly one eligible virtual stereo sink, verify name, session cookie, object serial, bound ID and class, read stereo Props, then issue all writes on that proxy and synchronize before exiting. Ordinary steps use maximum cubic-root gain and preserve stereo balance. Compatibility steps use the cubic root of average power, cap the increment at 20 points, unmute first and permit a downward step from external boost. No PipeWire Audio upstream code was consulted as an implementation input for this revision. The helper calls the documented object manager, interest/constraint, node parameter and SPA pod interfaces. The developer context included the previous local implementation, so this process cannot be described as a blind clean-room implementation. Retain that distinction in any rights review. [WirePlumber scripting API](https://pipewire.pages.freedesktop.org/wireplumber/scripting/lua_api.html) · [Core cookie and synchronization](https://pipewire.pages.freedesktop.org/wireplumber/scripting/lua_api/lua_core_api.html).

**Icons.** New action glyphs were constructed in local key coordinates. A six-vertex polygon forms the speaker body. Horizontal and vertical strokes form gain marks, diagonal strokes form mute, paired quadratic curves depict sound, parallel tracks and crossbars depict faders, five vertical strokes depict level, and a circular arc with an open arrowhead depicts reset. No third-party icon library or external path file was used. The existing key renderer places these glyphs using its approved scale, color and layout. The separate VU Spectrum branding did not change. Earlier screenshots and archives are historical artifacts and should not be selected as cleared release assets solely on the basis of this runtime remediation.
